# Glow Trims

[English](../README.md) | 简体中文

Glow Trims 是一个适用于 Minecraft Java Edition 26.3 的 Fabric Mod，可通过合成给已有的盔甲纹饰添加荧光和平滑闪烁效果。

## 当前效果

- 支持任何带有原版盔甲纹饰的装备。
- 不限制盔甲材质、纹饰图案或纹饰材料。
- 只让纹饰图层发光，不会让盔甲本体发光。
- 在原版“升级”信息的纹饰图案和纹饰材料下方显示“荧光”和“闪烁”词条，颜色跟随纹饰材料。
- 可以使用发光墨囊或墨囊添加或移除荧光效果。
- 可以使用回响碎片或蜂巢添加或移除闪烁效果。
- 发光和闪烁是独立效果，可以单独使用，也可以同时存在。
- 保留装备原有名称、附魔、耐久度、纹饰、Lore 和其他物品组件。
- 没有纹饰的装备不能添加任一效果。
- 合成必须能改变对应效果：已有的效果不能重复添加，尚未添加的效果也不能移除。

效果使用自定义 Data Component `glow-trims:glowing_trim` 和 `glow-trims:shimmering_trim` 保存，不会修改原版的 `minecraft:trim` 组件。

## 运行要求

- Minecraft Java Edition 26.3
- Fabric Loader 0.19.5 或更高版本
- Fabric API
- Fabric Language Kotlin
- Java 25

## 让纹饰发光

在玩家背包的 2x2 合成区或普通工作台中，无序放入以下两种物品各一个：

```text
任意带纹饰的装备 + 发光墨囊
```

取出输出装备后，原有纹饰会在黑暗环境中保持明亮。装备没有原版盔甲纹饰时，合成区不会产生输出。

## 移除发光效果

在合成区或工作台中，无序放入以下两种物品各一个：

```text
带有荧光效果的纹饰装备 + 普通墨囊
```

输出装备会移除发光状态，恢复为正常受环境光影响的原版纹饰。纹饰图案和材料不会改变。

## 让纹饰闪烁

在合成区或工作台中，无序放入以下两种物品各一个：

```text
任意带纹饰的装备 + 回响碎片
```

输出装备的纹饰会以约 3 秒为周期，在 35% 到 100% 的亮度之间平滑闪烁。该效果不要求装备已经发光。

## 移除闪烁效果

在合成区或工作台中，无序放入以下两种物品各一个：

```text
带有闪烁效果的纹饰装备 + 蜂巢
```

输出装备会移除闪烁状态。该操作不会改变装备是否发光，也不会改变纹饰图案或材料。

## 查看效果

按 `F5` 切换到第三人称视角。Mac 键盘可能需要使用 `Fn + F5`。

可以进入较暗环境，或者使用以下命令切换到午夜：

```mcfunction
/time set minecraft:midnight
```

带有荧光效果的装备纹饰会保持全亮，而盔甲本体仍会随环境变暗。闪烁效果会持续改变纹饰亮度，在任何光照条件下都可以观察。
